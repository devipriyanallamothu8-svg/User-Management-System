# User Management System

A Java-based User Management System developed using Java Servlets, HTML, CSS, and Apache Tomcat.

## 📌 Project Overview

This project provides a simple web-based system for managing user information. It includes user registration, login, searching, deleting users, and logout functionality.

## 🚀 Features

- User Registration
- User Login
- User Logout
- Search Users
- Delete Users
- Simple and user-friendly web interface
- Java Servlet-based backend
- Apache Tomcat deployment

## 🛠️ Technologies Used

- Java
- Java Servlets
- HTML5
- CSS3
- Apache Tomcat
- Eclipse IDE
